# DSH 事件与 API 地图（实测，2026-10-18）

> 全部结论来自本机实测：解压会话日志 + 读 `app.asar` 内未压缩的宿主源码。
> 版本：DSH 桌面端（`app.asar` 182,794,869 B，2026-10-17 17:20）

## 一、事件（`ctx.on('session/event', (session, event) => …)`）

事件对象形状：`{ type, seq, time, data, surfaceOp? }`

| 事件 | 落盘 | `data` 关键字段 | 用途 |
|---|---|---|---|
| `turn/start` | ✅ | `{turn}` | 回合开始 → 亮浮窗 |
| `step/start` | ✅ | `{turn, step}` | 第几步 |
| `assistant/live-chunk` | ❌ **瞬态** | 形状未公开（见下） | token 级流式 |
| `assistant/message` | ✅ | `{turn, step, message:{content:[…]}, usage, stream}` | 一步的完整内容 + 真实 token 用量 |
| `tool/call` | ✅ | `{turn, step, callId, name, arguments}` | 当前工具 |
| `tool/result` | ✅ | `{turn, step, message, meta}` | 工具结束 |
| `turn/end` | ✅ | `{}` | **"用完了没有"的权威信号** |
| `user/message` | ✅ | `{content:[{type:'text',text}], source}` | 用户输入 |
| `session/title` | ✅ | `{title, messageSeqs, source}` | 对话名 |

`assistant/message.message.content` 是块数组，**思考与回答可分辨**：

```json
[{"type":"reasoning","text":"…"}, {"type":"text","text":"…"}, …]
```

`assistant/message.stream` 是这一步的完整 chunk 序列（`{type:'chunk', chunk:{type:'block-start', blockType:'reasoning', index:0}}`）。
**live-chunk 的实时形状没查到公开定义**，所以桥插件对它做了多形态兼容，并把首次样张写到
`~/.dsh/bullet/debug.jsonl`，重启后按真实形状校正。

## 二、动作 API（"打断并纠正"）

`@deepseek-ai/dsh-api-session-controller` 源码里的真实做法：

```js
const agent = ctx.agents.get(sessionId);            // 拿活着的 agent
agent.cancel({ kind: 'user' }, { keepInbox: true }); // 打断当前 turn，保留队列
agent.steer(message);                                // 打断并纠正（改航）
agent.followup(message);                             // 不打断，排队
```

`message` 用 `@deepseek-ai/dsh-llm` 导出的 `createUserMessage({ content, source })` 造：

```js
content: [{ type: 'text', text: '停，你点错页面了' }]
source : { kind: 'user', rpcId: randomUUID(), clientTimeZone: 'Asia/Shanghai' }
```

同包还导出 `assistantStreamChunks` / `AssistantStreamAccumulator`，用于消费流式增量。
profile 的 `cordis.patch.yml` 里 `ui-conversation.busyEnter` 默认就是 `steer`
—— 说明"忙时回车=改航"本来就是产品行为。

## 三、会话日志

`~/.dsh/sessions/<workspace>/session-<uuid>/session.v4.jsonl.zstd`

- zstd，**每次 flush 压一帧**（实测 331KB = 181 帧）⇒ 外置跟随可增量读，不必整份解压
- 读之前**先拷贝副本**，不要在活动会话上跑第二进程（见全局 AGENTS.md：会误判日志损坏）

## 四、浮窗侧（Windows）

| 需求 | 做法 |
|---|---|
| 鼠标穿透 | `WS_EX_TRANSPARENT` + `WS_EX_NOACTIVATE`（在对顶层 hwnd 上设，`GA_ROOT` 取） |
| 不抢焦点 | 同上；映射窗口后把焦点还给原窗口 |
| 不进 agent 自己的截图 | `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`（Win10 2004+） |
| 透明背景 | tkinter `-transparentcolor`；面板本身实底更清晰 |
| DPI/多屏 | `SetProcessDpiAwarenessContext(-4)` |

**踩坑记录**：`pythonw.exe` 下 `sys.stdout` 是 `None`，开头 `sys.stdout.reconfigure()` 会直接崩；
日志必须写文件。**分层交互**（上方穿透 / 下方可点）留给阶段 2：单窗口挂 `WM_NCHITTEST`，
按坐标返回 `HTTRANSPARENT` / `HTCLIENT`。
